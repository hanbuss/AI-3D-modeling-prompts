# PROMPT · 现代简约别墅复刻提示词

> 把下面**整段**喂给任意具备「文件读写 + 命令行 + Blender」能力的 AI Agent，
> 再附 4–6 张同风格的现代简约别墅与庭院实景照片，即可从零复刻本项目。
> 每一条硬约束都是实际踩坑后写进去的，照做能少走 80% 的弯路。

---

## 0. 角色与目标

你是一名建筑可视化工程师。用 **Blender 5.x + Python 脚本**程序化生成一栋
**三层现代简约别墅 + 225 m² 庭院**，并交付一个**可旋转、可分层、可剖切**的网页查看器。

交付物必须是**可一键重建的工程**，而不是手工 .blend：

```
build.py            总装：场地 → 建筑 → 院子 → 室内 → 灯光 → 相机 → 导出 GLB
audit.py            布局审查（越界/穿墙/丢材质/退化面），必须 PASS
render_shots.py     效果图（day / dusk / night）
plan_shots.py       分层俯视平面
lib/kit.py          几何内核：GB 累积式构建器 + Ctx 图层/房间元数据/导出 + boxUV
lib/mats.py         基础材质（接可平铺贴图）
LAYOUT.md           坐标与房间尺寸的唯一真源
```

## 1. 先读图，再定语言（不要边看图边建模）

从参考图里提炼出**四条可执行的材料语言**，写进设计说明，然后才开始写代码：

1. **三块材料、两种明度**：浅色石材大板（亮）+ 暖柚木（中）+ 近黑金属（暗）。没有第四种。
2. **立面是平面**：大块安静的面、细缝收口，不靠装饰线脚。**平屋面 + 薄挑檐，不起翘、不做大坡顶**。
3. **洞口开到底**：一层客厅/餐厅通高落地玻璃，室内暖光外溢，夜景全靠这个。
4. **竖向格栅做对比**：木格栅竖条压在石材大板旁，一格一格看得清，是整栋唯一的"纹样"。

体量关系：**三层只占西侧**，东侧退成 2F 屋面上的**露天露台**——鸟瞰才有第三个层次。

## 2. 坐标契约（写代码前先建这一份，之后所有模块只读它）

- Blender：Z 向上，+Y = 北（房子背后），−Y = 南（院子在 −Y，临街）。单位米。
- 场地 **18 × 24 m**；建筑 **14.4 × 10.5 m**；前院 **18 × 12.5 m = 225 m²**。
- 三层，层高 **3.15 / 3.00 / 3.00**；室内外高差 0.15；楼板厚 0.30。
- 外墙**外皮** X ±7.20 / Y −1.50…9.00，厚 0.30 → **内皮** X ±6.90 / Y −1.20…8.70。
- 内隔墙 0.20。
- 屋面：平屋面 + **0.55 m 薄挑檐**，板厚 0.18，深灰金属收边，女儿墙 0.55。

> **必须把"内皮"和"房间盒"分开写清楚。** 两者差一个墙厚（0.30），
> 室内按外皮摆家具会让 0.60 m 的衣柜有 0.28 m 埋进墙里——这是最容易返工的一条。

**平面逻辑**：一层公共（门厅居中、西侧客厅、东侧餐厅 + 厨房、后勤压北侧、楼梯核心贴北墙）；
二层私密（西半层主卧套房、东侧次卧套房、洗衣与书房角居中）；
三层静谧（书房、客卧、茶室 + 露台）。**公私分开、干湿分开、动静分开。**

## 3. 庭院五组十一要素（院子是主角，房子是背景）

参考图里院子占画面 2/3，所有照片都是院子上空斜俯拍。**建模预算要按这个分配**。

1. **铺装** —— 800×800 砂岩大板，**每块板单独建、留 6 mm 真缝**（缝是几何不是贴图）；
   分区之间用 0.12 宽黑花岗岩镶边，把院子切成「入户轴 / deck / 亭 / 枯山水 / 草坪」五块。
   板色变化**必须极弱**（85% 同色 + 15% 微差），否则会花成棋盘。
2. **柚木 Deck**（西侧 6.4×6.6）—— 板宽 0.14、缝 8 mm，抬高一级，边缘暗藏灯带；
   上面是户外厨房岛台（2.4 m 大理石台面，0.06 出挑 + 0.09 暗藏凹槽）与沙发组 + 火盆。
3. **格栅亭**（东侧 5.4×4.4）—— 四根深灰钢柱 + **顶部全跨条状格栅**（不要一半实顶，
   实顶在鸟瞰里就是一块黑板），下面是 2.2 m 长餐桌。
4. **水幕墙**（东墙 2.8 m）—— 石材背景 + 三道水幕跌进 0.45 m 宽水槽，槽里铺卵石、藏水下灯。
5. **枯山水 + 造型松**（东南 9×3.8）—— 白砂 + **绕石同心耙纹（真的做出 40 多圈凸起砂脊）**
   + 三块景石 + 苔岛上一棵造型松。这是视觉焦点：一块留白把院子的"吵"压住。

其余：西侧草坪 + 秋色叶乔木、汀步穿草坪、绣球与修剪球、白横格栅围墙压深灰顶、
玻璃院门、全院 20 盏灯（草坪灯 / 树射灯 / 台阶暗藏灯带 / 水下灯）、**院外街道 + 2 台停放车辆**
（每一张鸟瞰都会拍到街道，没有它房子像悬在空里）。

## 4. 灯光（三套预设，只改强度不重建场景）

- 太阳：单盏 SUN，角度 1.6°，色温约 5500 K 微暖，低角度出长影子。
- 天光：渐变天空（地平线暖灰 → 天顶蓝），world 直接当环境光。
- 补光：一盏 24×18 m 冷色区域光在南侧当天空漫射，避免背光立面死黑。
- 室内灯 23 盏（每间房按吊顶高度布点，暖色 2700–3000 K，餐厅用面光）。
- 园林灯 13 盏 + 树射灯 4 盏（SPOT 向上打树冠）+ 水景灯 4 盏。
- `day` / `dusk` / `night` 三套预设：只改 `energy` 与自发光强度。

## 5. 第三方素材（这一节能省掉一整轮返工）

**植被与户外家具用 PolyHaven（CC0）真三维模型**，不要用手搓球冠树。

下载要点：
1. `api.polyhaven.com` 必须带浏览器 `User-Agent`，否则 403。
2. `.blend` **不含贴图**（相对路径 `//textures/`）——只下 `.blend` 会得到品红资产、
   `pack_all()` 失败。**必须连 `files` 接口里 `include` 列出的贴图一起下。**
3. 预处理流水线：`transform_apply` 烘掉对象缩放 → 合并 → **归一化到"底面 z=0、XY 居中"** →
   `src_height` / `src_radius` 写进自定义属性 → 贴图降到 1024 并 `pack_all()` → 减面。
4. **实例共享 mesh data**，glTF 只写一份几何，摆放 100+ 处也不会把 GLB 撑爆。
5. **按自然高度 ±30% 使用**。5 m 的树拉到 8.5 m 会变细长扫帚；地被草本（0.2–0.4 m）
   当灌木拉到 0.9 m 会变细棍。**只有自然高 1.2 m 那一档才是真灌木。**
6. 别用 `jacaranda_tree` 这类 45 万张卡片的花树：减到 25k 会把叶子全砍光，只剩光杆。

**汽车**：素材库没有车型（PolyHaven 全库无 vehicle）。自己参数化建：
轿车 4.72×1.84×1.44（轴距 2.80、轮径 0.355）、SUV 4.65×1.92×1.66。
用**棱台堆车身、棱台做玻璃舱**（自然得到 A/C 柱倾角）、轮胎 + 轮辋 + 5 根辐条、
灯组/格栅/牌照/后视镜/排气。约 650 面一台，远看近看都站得住。

## 7. 十条硬约束（违反必返工）

1. **`GB.frame()` 是上下文管理器**，必须 `with`。不写 `with` 变换不进栈——
   曾让 4.8 万面的背景树全部堆在原点，相机被一棵"巨树"挡死。
2. **共面必然闪**：挑檐顶与屋面板底、竖格栅与墙面、框料与玻璃、女儿墙与屋面，
   任何两面贴合都会在 GLB 深度精度下闪烁。**拉开 ≥20 mm**（格栅离墙用 40 mm）。
3. **尺寸别越界**：每层 X/Y/Z 有明确带宽，越界就是穿模；`audit.py` 要逐层校验，
   室内还要单独校验"不穿出房子"。
4. **视图走廊**：背景林必须按机位半径剔除，否则相机埋在树里。
5. **大地面板 z 必须低于院内底板**，否则整块场地被草坪盖住。
6. **房间盒用内皮**，贴墙家具成组内收，只改单边会把柜体厚度压掉。
7. **建模别信 bbox**：bbox 全绿但铺装花成棋盘、树堆在原点、屋面盖住场地，
   只有**渲染出来看一眼**才发得现。每完成一段必须出图。
8. **几何合并成少量 mesh**：一个 `GB` 承载几百个图元，按层出 5–10 个 mesh，
   不要上千个物体。
9. **层名即 glTF 节点名**：`SITE / ARCH_1F / ARCH_2F / ARCH_3F / ROOF / COURT / INT_1F / INT_2F / INT_3F`，
   查看器靠它做楼层显隐，改名就断。
10. **查看器初始 fit 要排除 `SITE` 与 `COURT`**，只按建筑层算包围盒，否则会被大地面拉远成一个小点。
