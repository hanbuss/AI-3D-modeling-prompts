# 提示词：程序化科幻飞船 + 一键剖析页

> 用途：把这份文档**整段**喂给具备「文件读写 + 命令行 + Blender」能力的 AI Agent，产出一艘
> 可拆解的飞船模型和一个离线剖析页。本文里的每一条硬约束都是在真实项目里踩坑后才写下的，
> 照做能省掉一大半返工。
>
> 成品参考：[projects/03-aegis-7-starship/](../projects/03-aegis-7-starship/)
>
> 适用：硬表面/载具/机械/机器人一类"能被拆开的物体"。建筑类见另外两份提示词。

---

## 0. 开工前先定死这五件事

不写清楚这五件，模型一定会返工：

1. **坐标约定**：`+X 前 / +Y 右 / +Z 上`，单位米。写进 `lib/spec.py` 顶部注释，全工程不许改。
2. **一个数值真源**：所有尺寸只从 `lib/spec.py` 读（站位表、引擎位置、挂点、分组基线）。
   任何模块里手写坐标就是 bug 的种子。
3. **零件契约**：每个模块暴露 `build(M, col) -> list[Object]`，每件用
   `kit.part(ob, part_id, 中文名, English, group, 方向向量, order=...)` 打标。
   `group` 只许取 spec 里登记的那几个键。
4. **拆解顺序与爆炸向量由总装统一算**，模块不许各写各的。
5. **网页读取的两份元数据**：`manifest.json`（零件表）与 `ship_meta.json`（特效锚点）。
   前者是 Blender 坐标，后者是 glTF/three.js 坐标——**坐标空间必须分开记**，否则特效会飘。

## 1. 建造顺序（不许跳步）

```
spec（真源） → hull（外形内核） → mats（材质） → 一个最小总装能跑通
→ 拆分模块并行 → 总装验收 → 渲染 → GLB → 网页 → 无头验收
```

**第一步只要"能跑通的最小总装"**：三段基础船体 + 一个方块，`blender -b -P build.py` 出 GLB 就算过。
先证明管线通，再谈细节。

---

## 2. 外形内核的硬要求（这一段决定像不像）

- 剖面用**控制点**而不是单一公式：平顶甲板 → 肩部倒角 → **硬舷线** → 下舷 → 平底。
- 硬边处**复制顶点**：放样后棱才是硬的。并且放样时要**跳过重复顶点之间的退化四边形**，
  否则 glTF 会报 `mesh is not valid`。
- 表面采样必须与外形**严格一致**：对外提供
  `surf(x, th, off)` / `surf_n(x, th)` / `frame(x, th)` / `plate(x0,x1,th0,th1,…)`，
  实现方式是「射线 × 剖面多边形求交」。
- `th` 是**极角**：`th=0` 在 +Y 舷侧，`th=π/2` 在甲板正中，**左舷是 `π − th`**（不是 `−th`）。
- 贴付件（装甲板/天线/喷口/格栅）**一律**用 `surf()` 取点。0.5 m 以上的平板直接搭在 R≈2 m 的
  曲面上，会中间凸起、两端扎进壳里，远看像一道黑矛——曲面板必须真的按曲面生成。

**自检**：写一个独立探针，取 N 个站位 × M 个角度，验证采样点落在多边形上（误差 0）且法线朝外。
不要相信"看着对"。

---

## 3. 材质硬要求（决定网页里是不是塑料）

- glTF 的 metallicRoughness 贴图是 **R=AO / G=roughness / B=metalness**。一张灰度图同时喂 G/B，
  金属度会掉到 ~0.3，网页里立刻变灰塑料。
- glTF 导出器**只认 `Base Color ← Image Texture` 直连**。中间插 Mix/Multiply 会被丢弃，
  整个模型变成一坨纯色。所以：**每个涂装色生成一张带色调的 albedo 贴图**，`baseColorFactor` 留白。
- 贴图一律 numpy 生成 → 自写 PNG 落盘 → `bpy.data.images.load`。
  `image.pixels.foreach_set` 在某些 5.x 场景会把数据写成 0（读回全黑 → roughness=0 → 镜面白）。
- 船壳需要三件套：albedo（斑驳 + 板缝 + 铆钉）、normal（缝边倒角）、ORM（缝里更脏更粗糙）。
  只靠几何做板缝，近景会显得"太干净"。

## 4. 拆分模块并行（多 Agent 时这样切）

一个文件只有一个写者，Lead 独占 `spec / hull / kit / mats / build / 渲染 / 验收`：

| 模块 | 负责内容 | 预算（三角面） |
|---|---|---|
| `fore.py` | 座舱（弧形舱盖 + 内饰）/ 鼻锥传感器 / 进气口 | 25k–60k |
| `mid.py` | 背脊骨架 / 装甲分块 / 散热板 / 舱门 / 涂装编号 | 30k–70k |
| `aft.py` + `fx.py` | 引擎吊舱 / 喷管 / 涡轮叶片环 / 尾焰与激光网格 | 35k–80k |
| `wings.py`/`weapons.py`/`gear.py` | 机翼 / 武器 / 起落架 | 40k–90k |
| `viewer/` | 离线剖析页 | — |

给每个 Agent 的任务描述必须包含：**唯一可写文件、零件清单、预算、验收命令、要看哪张图**。

**Lead 必须做两件保底**：
1. `build.py` 里逐模块 `try/except`，一个模块挂掉不能拖死整场；
2. 关键部位（引擎、尾焰）准备一份 Lead 自己的兜底实现，模块缺席时自动顶上。

## 5. 总装与验收（四条硬门）

1. **模块全部加载**：日志里 0 个 `!! MODULE x FAILED`。
2. **零件全部打标**：每件都有 `part_id`，id 唯一；`group` 取值合法。
3. **几何体检**（写 `tools/audit.py`）：零面积面、NaN 顶点、**浮空件**（与所有其他零件包围盒
   间距都超过阈值）、**爆炸向量**（为 0 或过大都报）。
4. **GLB 体检**：用脚本读 GLB 的 JSON chunk，确认 `baseColorTexture / metallicRoughnessTexture /
   normalTexture` 都在，`baseColorFactor` 全为 1。

爆炸向量统一算的公式（`build.refine_explode`）：从全舰包围盒中心指向每个零件包围盒中心，
按组加权（前段 ×1.15 向前、机翼武器 ×1.25 向外），再乘组基准幅度，组内按离舰体中心距离排序决定序号。
幅度别超过舰长的 1/3，否则爆炸图会变成一堆远处的碎点。

## 6. 渲染（成品图）要求

- EEVEE + 程序化 equirect 环境图（一张图定义所有高光形状），加 4–6 盏面光。
- **不要把飞船摆在地上**：深色背景 + 影棚反射，比"模型摆在灰地上"高级一个档。
- 曝光用负值压（`view_settings.exposure ≈ -0.85`）；金属要亮、漆面别糊成白的。
- 合成器加辉光：Blender 5.x 里 `CompositorNodeGlare` 改成 socket 参数
  （`inputs['Type'] = 'Bloom'`、`Threshold`、`Strength`、`Size`），按老写法取 `glare_type` 会静默跳过。
- 机位至少 8 个：主视角 / 侧视 / 俯视 / 首视 / 尾视 / 座舱特写 / 引擎特写 / 爆炸图；
  激光或尾焰单独来一张。焦距要按物体尺寸算，32 m 的舰用 95 mm 会切掉半个舰身。

---

## 7. 网页（剖析页）要求

- **单文件离线**：模型 base64 内嵌（`file://` 下 fetch/XHR 会被拦），three.js 用全局脚本版
  （r160 的 UMD + 全局版 GLTFLoader/OrbitControls/RoomEnvironment），不要用 import map。
- **一键剖析**：按 `order` 错峰飞离，`delay = order×8ms`、`easeOutCubic`、1.1 s；
  拆解滑杆 + 爆炸幅度滑杆；组头「只拆这组」。
- **取景要在动画之后**：立刻 refit 拿到的是"还没飞出去"的包围盒，爆炸图会被拍成一堆小点。
  用 `setTimeout(..., lastDelay + PART_MS)` 再算。
- **尾焰**：3 层加法混合锥 + 细亮芯 + 喷口光斑；`AdditiveBlending` + `transparent` +
  `depthWrite:false` + `toneMapped:false`，锥体沿引擎轴向，开口端半径取喷管出口内径。
- **激光**：内芯 + 外晕双层柱 + 端头光球，同样 `toneMapped:false`（否则被色调映射压灰）。
- **验收**：headless Chrome + CDP 截图（至少 4 张：合体/全拆/尾焰/激光），捕获 `console` 与
  `pageerror`，有 error 退出码非 0。页内再放一份断言脚本（模型件数、分组数、特效层数）当回归。

## 8. 常见返工原因（照这张表排查，能省两轮）

| 现象 | 真因 |
|---|---|
| 成品像香肠 | 剖面用了超椭圆 + 平滑着色，硬棱被抹掉 |
| 装甲板浮空 / 扎进壳里 | 手写坐标，没走 `surf()`；或 `th` 的左右舷符号搞反 |
| 网页里整舰纯白 | glTF 丢了 baseColor 贴图（中间插了 Mix 节点） |
| 网页里像灰塑料 | 金属度贴图通道用错（该走 ORM） |
| glTF 报 mesh not valid | 放样没跳过硬棱处的退化四边形 |
| 爆炸图像一堆碎点 | 爆炸向量各写各的 / 幅度过大 / 取景在动画结束前算了 |
| 尾焰像奶油筒 | 平涂自发光锥，没有沿长度的亮度与透明度衰减 |
| 成品图没有辉光 | Blender 5.x 的 Glare 节点改成 socket 了 |
