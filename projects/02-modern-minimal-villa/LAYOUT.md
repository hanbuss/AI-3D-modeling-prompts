# 现代简约别墅 · 坐标与模块契约（唯一真源）

参考图：现代简约小院 300 平实景照片 5 张（第三方网图，未随仓库分发）。
本文件是所有模块的唯一坐标真源。任何模块不得私自改动这些数字；需要改动先改本文件。

## 0. 世界坐标约定

- Blender：Z 向上，+Y = 北（房子背后），−Y = 南（院子在 −Y 一侧，临街）。
- 单位：米。所有函数参数都是米。
- 原点 (0,0,0) 在**房子南立面中线与场地地面交点**。
- 地面基准 z = 0.00（院内地坪）。门厅室内地坪 +0.15（一级台阶高差），室内统一 +0.15。
- 所有模块用 `lib.kit.GB()` 累积几何，`Ctx.mesh()` 出对象。禁止直接 `bpy.ops.mesh.primitive_*`。

## 6. 模块分工（文件归属，禁止交叉写）

### 6.0 分层名（COLLECTION / 空物体节点名）—— 查看器按层显隐，必须严格用这些

| 层名 | 内容 |
|---|---|
| `SITE` | 场地底板、街道、远景（Lead 负责） |
| `ARCH_1F` | 1F 楼板、外墙、门窗、幕墙、木格栅、石材、入户门 |
| `ARCH_2F` | 2F 同上 + 南向悬挑阳台 |
| `ARCH_3F` | 3F 同上 + 露台玻璃栏板 |
| `ROOF` | 平屋面、女儿墙、挑檐、屋面设备（空调外机、检修口） |
| `COURT` | 南院全部（court.py 独占） |
| `INT_1F` / `INT_2F` / `INT_3F` | 各层室内家具软装（rooms.py 独占） |

调用方式：`ctx.use("ARCH_1F")` 切换当前层，之后 `ctx.mesh(gb, "名字")` 落在该层。
层名会被导出成 GLB 的节点名，查看器直接按名字找。

### 6.1 文件归属

| 文件 | 负责 | 必须导出 |

## 7. 房间元数据（查看器要用）

`ctx.room(id, zh, en, floor, pos, area, desc)`，`pos` 传 `(x, z, y)` → 落盘自动转 glTF Y-up。
房间 id 用英文小写下划线：`foyer living dining kitchen master master_bath bed2 study guest terrace ...`

## 8. 硬性验收（自己先跑，别交上来才发现）

1. `python -c "import ast;ast.parse(open('lib/xxx.py').read())"` 语法过。
2. 无 `bpy.ops.mesh.primitive`、无 `bpy.context.scene.objects.link` 之类旧 API。
3. 不写 `villa/` 目录下任何文件；只写 `mvilla/lib/<你的文件>`。
4. 所有几何必须落在自己负责的 X/Y/Z 范围内，越界会在总装时看出穿模。
5. 材质名必须来自 `lib/mats.py` 的 SPEC 或 `lib/mats2.py` 新增；写错名字会在构建时 WARN auto-created。
